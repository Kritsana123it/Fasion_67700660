# ตรวจจับเสื้อผ้าด้วย YOLOv11 (Fashion Detection)

เว็บสำหรับตรวจจับประเภทเสื้อผ้าในรูปภาพ ใช้โมเดล **YOLOv11** ที่แปลงเป็นไฟล์ ONNX แล้วรันบนเบราว์เซอร์โดยตรงด้วย **ONNX Runtime Web** (ไม่ต้องมีเซิร์ฟเวอร์ประมวลผล)

## คลาสที่ตรวจจับได้

| คลาส | ความหมาย |
|------|----------|
| `shirt` | เสื้อ |
| `skirt` | กระโปรง |
| `trousers` | กางเกง |

## ไฟล์ในโปรเจกต์

- `index.html` — หน้าเว็บหลัก
- `script.js` — โค้ดโหลดโมเดล ประมวลผลรูป และวาดกรอบผลลัพธ์
- `labels.json` — รายชื่อคลาส
- `fashion.onnx` — โมเดล YOLOv11 ที่เทรนแล้ว

## วิธีรันด้วย Live Server

1. เปิดโฟลเดอร์โปรเจกต์ใน **VS Code**
2. ติดตั้งส่วนขยาย **Live Server** (ของ Ritwick Dey) จากแท็บ Extensions
3. คลิกขวาที่ไฟล์ `index.html` แล้วเลือก **Open with Live Server**
4. เบราว์เซอร์จะเปิดหน้าเว็บขึ้นมา (เช่น `http://127.0.0.1:5500`)
5. กดเลือกรูปภาพ ระบบจะแสดงกรอบและชื่อคลาสของเสื้อผ้าที่ตรวจเจอ

> หมายเหตุ: ต้องเปิดผ่าน Live Server (หรือเว็บเซิร์ฟเวอร์อื่น) เท่านั้น ถ้าดับเบิลคลิกเปิด `index.html` ตรงๆ เบราว์เซอร์จะโหลดไฟล์ `fashion.onnx` ไม่ได้
